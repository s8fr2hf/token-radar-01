Token Radar ranks every pre-token protocol in a sealed DefiLlama snapshot by what its token launch would be worth. The multiple is not a guess: each sector is priced off the live protocols in that sector that already trade, then adjusted for seven-day growth, maturity and chain breadth. The dashboard is a filterable board with a detail view and six-step farm plan for every protocol, a live-token view, and a model sandbox that recomputes the ranking in the page.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
